Ray OS

Konten, affiliate, kerja, kuliah, target, review, dan historis dalam satu dashboard.

CRUD FINAL: data penting punya Tambah, Edit, Delete, Restore, dan Hapus Permanen di Trash. Audit log tersedia.   Baseline posting: 25 slot / minggu sesuai jadwal posting yang disepakati. Target pilar default tetap 6 Affiliate + 3 Value + 2 Personal Brand dan dapat diubah di Goals. Affiliate diuji lewat 2 TikTok + 2 Shopee + 2 Tokopedia. Ini target operasional, bukan hukuman mati kalau minggu lu lagi digilas kerja dan kuliah.
